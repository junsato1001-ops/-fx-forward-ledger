# Data Implementation Gate — CFTC TFF(日本円)

- 対象: M1-MACRO-DATA-AVAILABILITY-V1 §3 の実装前 Gate(TFF の利用開始可能日、円の契約コードの存在と変遷)
- 実施: 2026-10-16(Claude)。GitHub Actions の `data-implementation-gate`(run 38917941639)で、CFTC の公式年次ファイルを取得した
- 読んだ列: 契約名(Market_and_Exchange_Names)、契約コード(CFTC_Contract_Market_Code)、報告日(Report_Date_as_…)の3列だけ。**建玉の列は読まず、保存も表示もしていない**(Performance Seal INTACT)
- 機械的な出力: `gate/cftc_tff_jpy_metadata.json`(各ファイルの SHA-256 と、該当する契約の全報告日)

## 1. 契約コード

- **097741 = JAPANESE YEN - CHICAGO MERCANTILE EXCHANGE**。2006〜2016年の一括ファイルと、2010〜2026年の年次ファイルのすべてで、同じコードと同じ名前だった(変遷なし)。
- 報告日は 2006-06-13 〜 2026-10-06 で、重複を除いて 1,061 件。一括ファイルと年次ファイルで重なる 2010-07-20〜2016-12-27 の報告日 337 件は、完全に一致した。
- 7日間隔でない箇所は 22 か所あった。すべて祝日の週に報告日が月曜または水曜にずれたもので、欠けた週はない。報告日の曜日の内訳は、火曜 1,047、月曜 13、水曜 1。
- 円に関係する他の契約(参考、V1 では使わない): 240743 日経平均(円建て)、399741 ユーロ/円クロス(CME、報告がない週がある)、299661 ユーロ/円(ICE、2006〜2007年)、597741 ユーロ円 TIBOR(2008年まで)。

## 2. TFF の利用開始可能日(Report Date ≠ Publication Date)

一次資料で分かったこと:

| 日付 | 出来事 | 出典 |
|---|---|---|
| 2010-07-22 | CFTC が TFF 報告の公表を始めると発表。「過去4年分のデータも近く公表する予定」 | CFTC Release 5857-10 |
| 2010-07-20 | 年次ファイルの最初の報告日(2010年のファイルは「2010-07-20 から」) | Historical Compressed のページ |
| **2010-12-03(金)** | **2006年以降の TFF の過去分(4年余り)を公表** | CFTC Release 5943-10(2010-12-06 付) |

結論:

- **2006-06-13〜2010-07-13 の報告日の値は、2010-12-03 まで世の中に存在しなかった**。報告日の時点で使うと、そのまま look-ahead leakage になる。
- 2010-07-20〜2010-11 の報告は、通常どおり公表されたと考えられるが、個々の公表日は一次資料で確認できていない。

**Gate の判定(案)**: TFF を使う特徴量は、**T_info が 2010-12-06 の終わり(米国東部時間)より後の Origin、つまり 2010-12-08(JST)以降の Origin から**使う。

- 根拠: 過去分の公表日(12/03)の時刻は不明で、確認できる最も早い公式資料が 12/06 付の発表。そのため 12/06 の終わりを上限にする。
- それより前の Origin では、TFF の特徴量は MODEL_PREREQ_UNAVAILABLE になる。
- 2010-12-08 以降の Origin では、2006 年以降の過去の報告を、標準化などの過去の窓に使ってよい(その時点で公表済み)。
- 2010-12-08 以降に報告日を持つ報告は、Matrix §3 の規則で公表時刻の上限を決める。

## 3. 残り

- 日銀・FOMC の日程(Matrix §2 C7)の再構築は別の Gate で行う。
- TFF の開始が 2010-12 になることで、M1-MACRO の学習と評価に使える期間がどう変わるかは、Transformation Spec の ⑥(欠測時の特徴量ベクトル)と合わせて決める。
