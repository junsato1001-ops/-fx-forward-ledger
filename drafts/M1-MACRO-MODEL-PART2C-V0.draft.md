# M1-MACRO Model Spec — Part 2-C: 正則化(案 v0)

- 状態: DRAFT(Claude、2026-10-17)。むすびの監査待ち。
- 前提(すべて Freeze 済み): M1-MACRO-MODEL-PART1-V1、PART2A-V1(損失 = CRPS / σ_M0)、PART2B-V1(Origin の重み)、Transformation の Part 1・2A・2B
- 封印: 係数、損失の値、特徴量の値や分布、成績は見ていない。
- 範囲: Freeze 済みの目的関数 J_{t,h}(β)(Part 2-B)に罰則を加えるかどうか、加えるなら何をどの強さで加えるか。損失と Origin の重みには触れない。warm-up と符号の制約は後の段。

## 1. 正則化に求める役割

| 役割 | 内容 |
|---|---|
| (a) 解を1つに決める | 損失(CRPS)は区分的に1次なので、最小値をとる β が1点に決まらないことがある(Part 2-A §4) |
| (b) 推定の誤差から守る | 標本が少ない時期に、雑音で β が大きくなり、親(S0)から不必要にずれるのを防ぐ |

## 2. 前提として確認すること

- β は Horizon あたり3つ以下(USDJPY が F_US を持つので3つ。Part 2-B)。
- 推定に使える Origin は、F_POS の開始(2010-12-08)から Forward の開始(2026年10月以降)までで、1W・4W で約 15年分(約 800 の週次の Origin)、1D ではその約5倍になる(Origin の数は公表の暦から決まる。値は見ていない)。
- したがって、データに依存しない固定の強さの罰則は、Forward の確認的な期間では効果がほとんど残らない。たとえば「β = 0 を n0 個の Origin 分の重みで信じる」罰則は、n0 = 52(1年分)なら、標本が約 800 の時点での影響は目安として n0 / (n0 + 800) ≈ 6% 程度にとどまる(損失が区分的に1次で罰則が2次なので、厳密な比率ではなく目安である)。
- 一方で、罰則の強さ(λ)を決めること自体が、新しい自由度になる。

## 3. 案: 罰則を置かない(λ = 0)。解が1つに決まらないときは、決定的な規則で1つを選ぶ

**β_{t,h} = 最小値をとる β の集合のうち、L2 ノルム ‖β‖₂ が最も小さいもの**

理由:

1. **役割 (a) は、罰則なしでも規則で果たせる**。最小値をとる β の集合は凸(区分的に1次の凸関数の最小値の集合)なので、その中で L2 ノルムが最小の点は1つに決まる。
2. **役割 (b) は、この段では負わせない**。§2 のとおり、固定の強さの罰則は確認的な期間でほとんど効かない。効くのは標本の少ない初期だけで、そこは過去の再生(prequential replay)の期間であり、性能の証拠ではない(M1-VOL と同じ扱い)。初期の推定の不安定さには、warm-up の段(β を推定し始める条件)で対処する。
3. **λ の自由度を持ち込まない**。λ を固定値にするにも、データから選ぶにも、根拠を値を見ずに示す必要がある。罰則を置かなければ、その自由度そのものが生じない。

## 4. 採らない案

| 案 | 採らない理由 |
|---|---|
| L2(Ridge)で λ を固定 | 一意になる利点はあるが、λ の値に値を見ない根拠がない。特徴量の単位(100bp、建玉の比率)と損失の単位(CRPS / σ)が違うので、λ の大きさの意味が特徴量ごとに変わる |
| L2 で λ を過去の機会からの交差検証(prequential CV)で選ぶ | 時点ごとの過去だけを使えば先読みにはならないが、候補の格子、選ぶ基準、同点の規則という自由度が加わり、推定が入れ子になる。V1 で必要な理由がない |
| L1(Lasso) | 狭義凸でなく一意にならない(Part 2-A §4)。特徴量の選択の役割を持つが、特徴量は Part 1 で固定済みで、選択を推定に任せる理由がない |
| 「親からのずれ」(μ / σ)の大きさに罰則を掛け、その強さを擬似的な Origin の数 n0 で決める | 単位の問題は解けるが、n0 の値に根拠が要る。§2 のとおり、確認的な期間での効果はほとんどない |

## 5. 決めておくこと(案)

1. **数学的な定義**: β*_{t,h} = argmin { ‖β‖₂ : β ∈ argmin_β J_{t,h}(β) }
2. **計算**: 決定的な方法で解く(乱数を使わない)。たとえば、線形計画で J の最小値 J* を求め、次に J(β) ≤ J* の範囲で ‖β‖₂ を最小にする2次計画を解く。
3. **数値の許容誤差**: 浮動小数点の計算なので、「J(β) ≤ J*」は J* に対する相対的な許容誤差の中で判定する。値は実装仕様で固定し、独立の実装との照合でも同じ値を使う(この値は推定の結果の解釈を変えない、計算上の定数である)。
4. **独立の照合**: Claude の独立の実装で、各 Origin の β* と J* が許容誤差の中で一致することを、実装の検査に含める。

## 6. むすびに確認してほしいこと

1. 罰則を置かず、解の一意性を「L2 ノルムが最小の解」の規則で決めることでよいか。
2. 推定の不安定さへの対処を、正則化ではなく warm-up の段に送ることでよいか。
3. §2 の見積もり(固定の強さの罰則は確認的な期間でほとんど効かない)を、罰則を置かない理由として使ってよいか。値は見ず、Origin の数(暦から決まる)だけを使っている。
