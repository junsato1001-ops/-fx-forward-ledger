## 1. 正則化に求めうる役割

| 役割 | 内容 |
|---|---|
| (a) 解を1つに決める | 損失(CRPS)は区分的に1次なので、最小値をとる β が1点に決まらないことがある(Part 2-A §4) |
| (b) 推定の誤差から守る | 雑音で β が大きくなり、親(S0)から不必要にずれるのを抑える(縮小) |

## 2. 前提として確認すること

- β は Horizon あたり3つ以下(USDJPY が F_US を持つので3つ。Part 2-B)。
- 特徴量の集合、特徴量の尺度、損失(CRPS / σ_M0)、Origin の重みは、すべて Freeze 済みである。
- 罰則の強さ λ について、データに依存しない自然な尺度は現時点でない。特徴量の単位(100bp、建玉の比率)と損失の単位(CRPS / σ)が違うので、λ の大きさの意味は特徴量ごとに変わる。
- λ を導入すれば、その値を固定するにせよデータから選ぶにせよ、新しい選択の自由度が生じる。
- 参考(理由には使わない): 推定に使える Origin は、F_POS の開始(2010-12-08)から Forward の開始までで、1W・4W で約 800、1D でその約5倍になる(公表の暦から数えた。値は見ていない)。

## 3. 案: 罰則を置かない(λ = 0)

**主な理由: 自然な罰則の尺度が事前に存在せず、λ という追加の自由度を導入しない。** V1 は、Freeze 済みの小さな固定のモデルを、prequential にそのまま推定するものとする。

- 役割 (a)(解を1つに決める)は、§5 の同点の規則で果たす。
- 役割 (b)(縮小)は、V1 では持たない。

**帰結(受け入れる)**:

- 推定を始める前の標本の不足は、Warm-up Spec で扱う(β を推定し始める条件)。
- **ただし warm-up は正則化の代わりではない。** warm-up は推定を始める前の不安定な期間を避ける仕組みであって、warm-up の後に係数のばらつきを継続的に縮める機能はない。V1 は、warm-up の後の係数の分散を縮小によって抑える機能を持たない。この帰結を受け入れる。

## 4. 採らない案

| 案 | 採らない理由 |
|---|---|
| L2(Ridge)で λ を固定 | 一意になる利点はあるが、λ の値に、値を見ずに示せる根拠がない(§2) |
| L2 で λ を過去の機会からの交差検証(prequential CV)で選ぶ | 時点ごとの過去だけを使えば先読みにはならないが、候補の格子、選ぶ基準、同点の規則という自由度が加わり、推定が入れ子になる |
| L1(Lasso) | 狭義凸でなく一意にならない。特徴量を選ぶ役割を持つが、特徴量は Part 1 で固定済み |
| 「親からのずれ」(μ / σ)の大きさに罰則を掛け、強さを擬似的な Origin の数 n0 で決める | 単位の問題は解けるが、n0 の値に根拠が要る。さらに損失が区分的に1次で罰則が2次なので、n0 を「何個分の Origin」と解釈すること自体が厳密でない |

## 5. 解を1つに決める規則(同点の規則)

1. **定義**: β*_{t,h} = argmin { ‖β‖₂ : β ∈ argmin_β J_{t,h}(β) }
2. **これは正則化でも縮小でもない。** CRPS の目的関数 J の最小値をとる β が1点に決まらない場合だけに使う、決定的な同点の規則である。**J を少しでも悪化させて β を 0 の方向へ縮めることは許さない。** J の最小化が常に優先し、最小値をとる β が複数あるときだけ、その中で L2 ノルムが最小のものを選ぶ。最小値をとる集合は凸なので、その点は1つに決まる。
3. **計算**: 乱数を使わない決定的な方法で解く。たとえば、線形計画で J の最小値 J* を求め、次に J(β) ≤ J* の範囲で ‖β‖₂ を最小にする2次計画を解く。
4. **数値の許容誤差**: 浮動小数点の計算なので、「J(β) ≤ J*」は許容誤差の中で判定する。許容誤差は、ソルバーの有限な精度に対応する実装上の定数であり、経済的・統計的なハイパーパラメータとして調整しない。値は実装の Freeze の前に固定し、独立の実装でも同じ値を使う(許容誤差が大きすぎると、J の最小値でない β が2段目に入りうるので、値は精度の範囲に限る)。
5. **独立の照合**: Claude の独立の実装で、各 Origin の β* と J* が許容誤差の中で一致することを、実装の検査に含める。
