## 1. 親モデル: S0-EMPCLIM-STD-EXP-V1

**案: M1-MACRO-V1 の親は S0 とする。M1-VOL-SHRINK-V1 にはしない。**

| 観点 | S0 | M1-VOL |
|---|---|---|
| 位置づけ | Freeze 済みの基準モデル(確認的な比較の相手) | Shadow / Pipeline Pilot。確認的な Challenger ではない |
| 幅(σ) | σ_M0(M0 の VOL_STATE_V1) | w による縮小で変わる |
| M1-MACRO の効果の分解 | 親との差が、位置のずらしだけになる | 位置の効果と幅の効果が混ざる |

理由:

1. 事前設計 §6 で「まずは位置のみ」とした。親を S0 にすれば、M1-MACRO と親の違いは位置のずらしだけになり、主比較(M1-MACRO vs S0)の差を位置の効果として解釈できる。
2. M1-VOL は Pilot であり、その σ は仕組みの検証のために出しているものである。確認的な Challenger の土台にする根拠はない。
3. この選択は、M1-VOL の成績、M1-MACRO の係数や損失を一切見ずに行う。

EVAL-SPEC-V1 での主比較は M1-MACRO-V1 vs S0。

## 2. 予測分布の構造: S0 の分布の位置だけをずらす

S0 の予測分布は、Origin t、ペア p、Horizon h について、標準化残差の pool {Z_i}(i = 1..N)を σ_M0,t 倍した離散経験分布である(各点に確率 1/N)。

**M1-MACRO-V1 の予測分布:**

- 各点: x'_i = σ_M0,t · Z_i + μ_{p,t,h}(i = 1..N、各点に確率 1/N)
- 位置のずらし: μ_{p,t,h} = Σ_{k ∈ N(p)} β_{k,h} · F_k(t)(y の空間、対数リターンの単位。Part 2-B)
- Point = σ_M0,t · mean(Z) + μ
- PI80 = [σ_M0,t · Z_(k10) + μ, σ_M0,t · Z_(k90) + μ](S0 と同じ順位 k10、k90)
- クラス確率: 共通の境界 b_t = 0.25 · σ_M0,t に対して、ずらした点 x'_i で数える(EVAL-SPEC-V1 §3.3)
  - P_Down = #{x'_i < −b_t} / N
  - P_Neutral = #{−b_t ≤ x'_i ≤ +b_t} / N
  - P_Up = #{x'_i > +b_t} / N
- CRPS などの評価: ずらした離散分布そのもの

**使う pool と σ は S0 とまったく同じ**(同じ Pool_N、同じ Z_i、同じ σ_M0,t)。M1-MACRO 自身の残差で pool を作り直すことはしない。

- 理由: 幅を S0 と同じに保ち、効果を位置だけに分けるため。
- 帰結(Freeze 文書に書いておく): 特徴量が y の一部を説明できる場合でも、pool は S0 のまま(説明される前の散らばり)なので、M1-MACRO の分布の幅は、説明できた分を差し引いた幅より広めになる。V1 ではこれを受け入れる。幅の調整は別の仕様で扱う。

## 3. 切片: 置かない

**案: μ には切片を置かない。μ = Σ β_k · F_k だけとする。**

理由:

1. 無条件の平均的な動き(ドリフト)は、親の S0 が mean(Z)(ペア別・Horizon 別の pool の平均)ですでに持っている。μ に切片を置くと、同じ役割を二重に持つことになる。
2. 切片がなければ、**すべての特徴量が 0 のとき、または係数がすべて 0 のとき、M1-MACRO-V1 は S0 と完全に一致する**(入れ子の関係)。M1-VOL が w = 0 で S0 と一致するのと同じ形で、実装の検査に使える。

**この選択に含まれる経済的な仮定(明記する)**: 各特徴量の 0 を「親からずれない中立の点」とみなす。

- F_US・F_JP: 0 は「20 source-business-days の間に2年金利が変わらなかった」。中立の点として自然である。
- F_POS: 0 は「Leveraged Funds の円の買いと売りが釣り合っている」。Part 1 で標準化をしないと決めたので、Leveraged Funds が長い間どちらかに偏っている場合も、その偏りの大きさがそのまま μ に入る。これは「平らなポジションからの偏りが巻き戻しの圧力になる」という Part 1 の仮説そのものであり、V1 ではこの中立の点を変えない(偏りの平均からの差を使う案は、標準化の窓の自由度を戻すことになるので採らない)。
- **F_POS = 0 は、平均からの偏差ではなく、Leveraged Funds の円の買いと売りが釣り合った状態として定義する(物理的・経済的な 0 を基準にする)。過去の F_POS が 0 を中心に分布していなかったことが後から分かっても、その事実を見て中心を変更しない。**

## 4. 位置のずらしと、予測の対象との関係(推定の損失は決めない)

**ここで決めるのは「S0 からの位置のずらし μ を推定する」ことまでである。β を何の損失で推定するかは決めない**(Model Spec Part 2 で、係数や成績を見る前に Freeze する)。

- 過去の Origin i で S0 が発行した中心(Point)を m_i = σ_M0,i · mean(Z)_i とする(発行時の値。遡って計算し直さない)。
- M1-MACRO-V1 の中心は m_i + μ_i、μ_i = Σ_{k ∈ N(p)} β_{k,h} F_k(i) となる。
- 中心からの残差は e_i = y_i − m_i と表せる。
- **二乗誤差の系統の損失**(OLS、Ridge など)を採る場合: (y_i − (m_i + μ_i))² = (e_i − μ_i)² なので、β の推定は「e_i と μ_i の誤差を最小にする問題」と同じになる。
- **分布の損失**(CRPS など)を採る場合: 「e_i を説明する」という形では定義できない。位置をずらした S0 の分布全体と、実現値 y_i から直接に損失を計算する(例: CRPS(F^{S0}_i(· − μ_i), y_i))。この場合、S0 の分布の形も損失に入る。
- どちらの場合も、使う機会は Part 2-A の complete case、Part 2-B の開発対象の3ペア、Horizon ごと、Target_End_i ≤ Last_Available_Fix_t(結果が確定したもの)に限る。

## 5. 予測を出す条件

M1-MACRO-V1 が (p, t, h) で FORECAST を出すのは、次をすべて満たすときだけである。

1. 親の S0 が同じ (p, t, h) で FORECAST を出している(S0 が MODEL_PREREQ_UNAVAILABLE なら、M1-MACRO も MODEL_PREREQ_UNAVAILABLE。理由コードは PARENT_PREREQ_UNAVAILABLE)
2. N(p) のすべての特徴量が定義できる(Part 2-A)
3. 係数が定義できる(warm-up の扱いは Model Spec Part 2。「特徴量はそろい、S0 も出ているが、係数がまだ推定できない」場合の Decision_Class も Part 2 で決める)

## 6. 方向の主張と DA Safety Veto

M1-MACRO-V1 は、親に対して方向(位置)の情報を主張するモデルである。したがって EVAL-SPEC-V1 §3.5 の DA Safety Veto が**適用対象**になる。具体的な規則は EVAL-SPEC-V1 と、別に定める決定の方針に従う。
