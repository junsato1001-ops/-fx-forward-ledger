## 1. 何を推定したいのか

M1-MACRO-V1 は、S0 の予測分布 F^{S0}_i を μ_i = X_i β だけ平行移動したもので(Model Part 1)、**評価されるのは予測分布そのもの**である。EVAL-SPEC-V1 の主指標は L = CRPS(F_t, y) / σ_M0,t。

したがって推定したいのは、「平行移動した S0 の分布の、主指標で測った予測の質を最もよくする β」である。条件付き平均のずれそのもの(パラメータとしての μ)を当てることは、V1 の目的ではない。

### CRPS の形の確認

S0 の分布は点 x_ij(j = 1..N_i、各 1/N_i)の離散分布なので、

CRPS(F^{S0}_i(· − μ), y) = (1/N_i) Σ_j |x_ij + μ − y| − (1/(2N_i²)) Σ_j Σ_l |x_ij − x_il|

第2項は μ によらない。したがって μ について最小化するのは第1項だけで、これは μ について凸で区分的に1次である。μ = X_i β なので、観測について足した損失も β について凸になる。

## 3. 案: B(CRPS / σ_M0)を採る

**1観測の損失: ℓ_i(β) = CRPS(F^{S0}_i(· − X_i β), y_i) / σ_M0,i**

理由(すべて理論上の基準で、データは見ていない):

1. **評価と同じ量を最適化する**。M1-MACRO-V1 は主指標で親の S0 と比べられる。学習で別の量(平均の二乗誤差)を最小にすると、評価で測る質とずれる。
2. **大きな誤差に対する増え方が1次**。Part 1 で切り捨てをやめ、大きな値への対処は Model Spec で扱うとした。この仕様の純粋な位置のずらしでは、β に依存する部分が絶対偏差の形になるので、二乗誤差と比べて、大きな予測誤差に対する損失の増え方が1次にとどまる。切り捨てという非線形の選択を戻さずに済む(ここでは breakdown point などの意味での「頑健」は主張しない)。
3. **S0 の分布の形と整合する**。M1-MACRO-V1 は S0 の分布の形をそのまま使う。その形のもとで最もよいずれを選ぶのが自然である。
4. **σ_M0,i で割るのは主指標と同じ**。これは観測ごとの重みを変えるだけで、β は y の空間のまま(Part 2-B の共有の単位を変えない)。値動きの大きい時期が推定を支配するのを防ぐ効果もあるが、それは採用の理由ではなく、主指標に合わせた結果である。

### 3.1 経験分布の CRPS の式(固定)

過去の機会 i について、S0 が発行した pool {Z_ij}(j = 1..N_i、各 1/N_i)と σ_M0,i から、位置をずらした点を

x'_ij = σ_M0,i · Z_ij + μ_i、μ_i = X_i β

とする。使う CRPS は次の式に固定する(EVAL-SPEC-V1 §3.1 と同じ。N_i(N_i − 1) で割る fair CRPS は使わない)。

CRPS_i(β) = (1/N_i) Σ_j |x'_ij − y_i| − (1/(2N_i²)) Σ_j Σ_k |x'_ij − x'_ik|

1観測の損失は ℓ_i(β) = CRPS_i(β) / σ_M0,i。

性質: すべての点に同じ μ_i を足すので、|x'_ij − x'_ik| = |σ_M0,i Z_ij − σ_M0,i Z_ik| となり、第2項は β によらない。したがって β の推定にとっては、

ℓ_i(β) = (1/N_i) Σ_j | Z_ij + (μ_i − y_i) / σ_M0,i | + (β によらない定数)

を最小化する問題になる。これが「β に依存する部分が絶対偏差の形になる」ことの正確な意味である。定数項は最適化には影響しないが、損失の値として報告・照合するときは上の CRPS の式全体を使う。

### 3.2 推定に使える機会(損失の計算可能性の条件)

σ_M0,i が有限かつ > 0 の過去の機会だけを、係数の推定の損失に使う(EVAL-SPEC-V1 §4.1a の METRIC_UNDEFINED_ZERO_SCALE と同じ考え方)。

- これは新しい欠測の規則ではなく、損失を計算できるための条件である。
- σ_M0,i = 0 の機会を、小さな値 ε で割る、1 に置き換えるなどの補正はしない。
- 除外した件数は記録する。

## 4. B を採る場合に決めておくこと

- **一意でない場合**: 損失だけでは、最小値をとる β が1点に決まらないことがある(区分的に1次のため)。最終的に一意にする規則は、正則化の仕様が決まった後に Freeze する。正則化が一意性を保証しない場合(たとえば L1 の罰則は狭義凸ではない)は、決定的な同点の規則を別に必ず定める。狭義凸の罰則(たとえば L2)を採る場合は、それで一意になる。
- **計算**: 観測あたり N_i 項の絶対値の和(N_i は S0 の pool の大きさ)。β は3次元以下なので、厳密な凸最適化(線形計画、または正則化があれば2次計画)で解ける。近似の方法(確率的な勾配など)は使わない。乱数を使わない決定的な方法にする。
- **値の確認**: 推定した β で計算した損失が、同点の規則も含めて独立の実装で再現できることを、実装の検査に入れる。

## 5. A を採らない理由のまとめ

- 平均を当てることは V1 の目的ではない(評価は分布の質)。
- 二乗誤差は大きな誤差に2乗で反応するので、Part 1 で切り捨てをやめたこととの組み合わせが悪い。
- A の利点(閉じた形、一意、簡単)は計算と検証の便利さで、B でも β が低次元なので代わりの手段がある。

## 6. 次(Part 2-B: Origin の重み)

損失はもう変えない。ペアの中 → Origin の中での集計 → Origin の間、のどこで平均するかだけを決める。σ_M0 で割ることは損失の定義(scoring rule)の一部で、Origin の重みとは別の層として扱う。
