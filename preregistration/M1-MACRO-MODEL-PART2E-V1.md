# M1-MACRO Model Spec — Part 2-E: 符号の制約(案 v0)

- 状態: DRAFT(Claude、2026-10-17)。むすびの監査待ち。
- 前提(すべて Freeze 済み): M1-MACRO-TRANSFORM-PART1/2A/2B-V1、M1-MACRO-MODEL-PART1/2A/2B/2C/2D-V1
- 封印: 係数、損失の値、特徴量の値、成績は見ていない。§2 の符号の向きは定義と経済的な推論だけから書いた。
- 範囲: 係数 β_{k,h} に事前の符号の制約を置くかどうか。

## 1. 符号の向きの突き合わせ(定義)

| 量 | 正の向きの意味 |
|---|---|
| y = log(P_End / P_Start) | P は XXX 1単位の円建ての価格。y > 0 は相手通貨が円に対して強くなった(円安) |
| μ = Σ β_k F_k | μ > 0 は、親の S0 の分布を円安の方向にずらす |
| F_US | 米国2年金利が過去 20 source-business-days で上がった |
| F_JP | 日本2年金利が過去 20 source-business-days で上がった |
| F_POS | Leveraged Funds が円先物を買い越している(円高の側に偏っている) |

したがって β_k > 0 は「F_k が正のとき、その後の円安を予測する」ことを意味する。

## 2. 経済的に考えられる符号(予測の係数として)

ここでの β は因果の効果ではなく、20 source-business-days の過去の変化や、過去の時点のポジションから、**その後の** y を予測する係数である。予測の係数としての符号には、どの特徴量でも、方向の違う仮説が両方ありうる。

| 係数 | β > 0 を支持する仮説 | β < 0 を支持する仮説 |
|---|---|---|
| β_US(USDJPY のみ) | 米金利の上昇がその後も米ドル高として続く(反応の遅れ、勢い) | 金利の動きに為替がすでに反応し、その後は戻る(行き過ぎの修正) |
| β_JP | 日本の金利の上昇に為替がすでに反応し、その後は戻る | 日本の金利の上昇がその後も円高として続く(反応の遅れ、勢い) |
| β_POS | 円の買い越しの偏りが巻き戻され、円安になる(巻き戻しの圧力。Model Part 1 §3 の説明) | 投機筋の偏りがその後の円高を先取りしている(勢いへの追随) |

Model Part 1 §3 では、F_POS の 0 を中立の点とする理由として「平らなポジションからの偏りが巻き戻しの圧力になる」と書いた。これは中立の点を定める説明であって、Transformation Part 1 の仮説は「レバレッジを使う主体の方向性のあるポジションと、その巻き戻しの圧力」であり、符号を一方に決めてはいない。

## 3. 案: 符号の制約を置かない(V1 の β はすべて制約なし)

理由:

1. **予測の係数としての符号を、値を見ずに一方に識別できる強い理論がない**(§2)。どの特徴量にも、方向の違う仮説が両方ある。
2. **制約は仮説を1つ加えることになる**。λ = 0(Part 2-C)と同じ方針で、根拠の弱い仮説を V1 の推定に持ち込まない。
3. **評価は両方向で行う**。EVAL-SPEC-V1 は優越と劣後の両方向を検定する。制約を置かないモデルの方が、この検定と対称である。
4. 参考: 制約を置いた場合、真の符号が逆なら推定値は境界(β = 0)に張り付き、M1-MACRO は S0 に近づく。害は小さいが、その特徴量の情報を捨てることになる。これは理由の主ではない。

## 4. 事前の予想を記録するか

**案: 係数の符号について、事前の予想は記録しない。**

- §2 のとおり、どの係数も両方向の仮説があり、一方を「予想」として書くことは、値を見る前の時点でも根拠が弱い。
- 予想を書くと、後で推定値の符号が予想と合ったかどうかで結果を解釈したくなる。予想が推定にも評価にも使われないなら、記録する意味が小さく、解釈の偏りの原因になりうる。
- 推定された符号の解釈(どの仮説と整合するか)は、確認的な評価が済んだ後の記述として扱う。

(代わりの案: §2 の表を「事前に考えられる両方向の仮説」としてそのまま記録しておく。これは一方に賭けるものではないので、上の懸念は小さい。§2 は Freeze する文書の一部として残す。)

## 5. 実装と記録

- β は制約なしで、Part 2-A の損失、Part 2-B の重み、Part 2-C の同点の規則で推定する。
- 各予測の行に β_{k,h} の値と符号を記録する(Model Part 1 §7 のとおり)。
